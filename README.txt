CAREE-UP 사용자 스펙 설문 추가판

1. 압축파일을 풀고 세 파일(index.html, reset-password.html, start_local.py)을 같은 폴더에 둡니다.
2. 실행 중인 이전 start_local.py가 있으면 Ctrl+C로 종료합니다.
3. python start_local.py 를 실행합니다.
4. http://localhost:8000/index.html 에서 로그인합니다.

SC_SPEC_INFO에 본인 레코드가 없는 경우에만 설문 팝업이 열립니다.
학년 → GPA → 기술 스택 → 자격증 → 선호직무(최대 3개) → 입력 내용 확인 순서입니다.
기술 스택과 자격증이 없으면 빈칸으로 넘어갈 수 있습니다.
마지막 두 버튼 모두 기존 save_user_spec 함수로 스펙과 선호직무를 함께 저장합니다.
- 직무추천 받기: 저장 성공 후 직무추천 탭으로 이동
- 조금더 둘러보기: 저장 성공 후 팝업을 닫고 현재 화면 유지
이미 스펙 레코드가 있으면 설문을 표시하지 않습니다.
조회 실패는 레코드 없음으로 처리하지 않습니다. 마이페이지에서 다시 불러오기를 눌러주세요.
기존 계정, DB 테이블, 비밀번호 재설정 주소 설정은 그대로 사용합니다. 새 SQL 실행은 필요하지 않습니다.

검증: HTML DOM 기반 로그인/설문/저장 흐름 및 기존 마이페이지 회귀 검증 통과.
이 환경에서는 브라우저 실행 파일이 없어 실제 화면과 실제 계정 저장은 별도 확인하지 못했습니다.
